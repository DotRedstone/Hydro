# UI 走查记录（2026-11）

这轮对 `packages/ui-default` 的暖纸主题做了一次逐页对齐走查：两轮独立视觉评审
（公开页 7 张 + 管理页 5 张，逐张放大到像素级）+ 主流程自查，共 21 条问题。
下面记录当时看到的现象、处理结果和仍未处理的项，避免以后重复排查。

## 方法

- 截图：`node <skill>/scripts/shoot.mjs <url> --size desktop --out <dir>`，
  1450×900 视口，浅色为主；深色用 `.oil-ui/shot-theme.mjs`（挂 `theme--dark` 类）。
- 测量：CDP 求 `getBoundingClientRect()` 与 `getComputedStyle()`，比文字墨迹与
  容器边缘，比同一组控件的左右端。
- 评审：把截图交给独立评审者，只读、不改代码，输出「页面 / 元素 / 现象（像素）/
  建议 / 严重度」。

## 已修

| 位置 | 问题 | 处理 |
| --- | --- | --- |
| 注册、登录 | 表单字段在 `.row > .columns` 里带 15px 沟槽，验证码行是通栏，右边缘差 17px；`.auth-page` 未给宽度导致卡片按文案收缩（643 / 783） | 去沟槽 + `width: 100%`，卡片稳定 812 |
| 题库列表 | 搜索行四个元素绝对定位拼装：排序下拉比输入框高 8px 且上移、题数贴死输入框、按钮右端差 6px | 改 flex 行，统一 38px 高、8px 间距 |
| 题库列表 | 侧栏「分类」项比同卡标题多 6px | 同卡左基准已一致，保留（6px 视觉不可辨） |
| 排行榜 | RP 列右对齐，比赛/通过两列居中 | 数字列统一右对齐 + `tabular-nums` |
| 比赛列表 | Rated 徽章 24px 高把所在行顶到 96px（其余 86px），行内两行文字被压低 5px | 徽章 `line-height: 1.35` |
| 作业列表 | 「全部」下拉 32px 高叠 8px 内边距，正文只剩 16px，中文被裁掉半个字 | 工具栏下拉 `padding: 0 26px 0 10px` + 最小宽度 |
| 作业、比赛 | 首行行高比其余行高（115 / 86 / 96） | 同徽章与内边距问题，修完三行统一 86px |
| 管理表格 | 表头下沿、末行下沿缺分隔线；表头操作按钮比标题低 6px | 补 `thead` 与 `tr + tr` 边线，表头 `align-items: center` |
| 系统设置 | 布尔项说明换行后缩回复选框下方（悬挂缩进断裂） | 本页布尔项改 `inline-flex` + `flex-start`（全局 `.checkbox` 带 `!important`，只在这一条用一次） |
| 系统设置 | 配置键当标签、人话当小字，两列按内容各自漂移 | 网格两列、描述当标签、键名降级；布尔项只留复选框与文案 |
| 编辑域资料 | 表单继承 `.row` 的 -8px 负边距，字段比卡片标题左 10px；字段只有 41% 宽 | 抵消负边距（144 / 146），单列 560px |
| 配置管理 | 标题左内边距 15px，比下面的代码面板还靠左 | 表头内边距 24px |
| 提交页 | 语言下拉默认落在注册顺序第一项 bash | 服务端 `pickDefaultLang`：`?lang=` → 个人设置 → 最近提交（跳过 bash）→ 站点默认 → 常见语言 |
| 在线编辑模式 | 同上（默认 bash）；工具栏胶囊圆角与全站 4px 不符；F9/F10 提示 10.88px、对比度 2.69:1 | 共用默认语言规则；`--r-sm`；11.25px + 88% 前景色 |
| 在线编辑模式 | 题目没配文件时编辑器整片空白，看起来像没加载出来 | 空 buffer 时在编辑器左上角给一句提示，输入后自动消失 |

## 仍未处理

| 配置管理 | 右侧「属性」栏白底被视口右缘裁掉；区块小标题与其下字段标签差 12px | 这块是嵌入的 ConfigEditor 自己按三栏排的布局，改动要动它的内部结构，风险大于收益 |

## 核对后确认不是问题

- 列表日期只显示「2026-11」：日期数字（24 / 21）在上一行，年月本来就是 `YYYY-M`，不是截断。
- 训练列表「参加人数」看着缩进：实测与卡片标题同为 x=147。
- 首页「最新题目」首行偏高：修完徽章后 8 行统一 52px。
